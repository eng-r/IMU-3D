# IMU-3D Backend — Minimal Setup Guide  
### (.NET 8 Web API - Windows)

This document describes how to install the .NET SDK on Windows, generate a minimal Web API project, place it into the desired folder structure, and run a simple IMU sample endpoint for initial testing.

## 1. Install .NET 8 SDK (Windows)

Install the **.NET 8 SDK** from Microsoft’s official website:

https://dotnet.microsoft.com/en-us/download/dotnet/8.0

Verify installation:

```
dotnet --version
```

## 2. Create the Backend Project

```
dotnet new webapi -n ImuBackend
```

## 3. Move Project into Project Structure

Move contents of `ImuBackend/` into:

```
backend/src/
```

## 4. Remove Template Files

Delete autogenerated files (if any), like:

```
WeatherForecast.cs
Controllers/WeatherForecastController.cs
```

## 5. Restore Dependencies

```
dotnet restore
```

## 6. Build

```
dotnet build
```

## 7. Run on Port 5000
Run in CMD session:
```
dotnet run --urls "http://localhost:5000"
```

## 8. Test via cURL (check output)
NOTE: the [```curl```](https://curl.se/) should be independently installed.

Run in another CMD terminal session:

```
curl http://localhost:5000/api/imu/sample
```
check that terminal shows:
```
{"timestamp":"2025-11-15T12:00:00Z","yaw":0.3,"pitch":-0.1,"roll":1.2}
```
